# 🇭🇰 香港 5 天 4 夜自由行指南 (一鍵啟動版)

本專案係根據 `5.tsx` 行程元件所構建的完整 React + Tailwind CSS + Vite 網頁應用程式。

---

## 🚀 一鍵啟動方式 (Windows)

只需要雙擊執行以下檔案即可自動安裝套件、啟動伺服器並打開瀏覽器：

* **`一鍵啟動.bat`** (或 `start.bat`)

---

## 💻 手動啟動方式 (終端機)

若您習慣使用 Command Prompt 或 PowerShell：

```bash
# 1. 安裝套件 (僅首次需要)
npm install

# 2. 啟動開發伺服器 (將自動開啟瀏覽器存取 http://localhost:3000)
npm run dev
```

---

## 🛠️ 技術架構

* **前端框架**: React 19 + TypeScript
* **建置工具**: Vite 6
* **樣式庫**: Tailwind CSS v4 (`@tailwindcss/vite`)
* **圖標庫**: Lucide React (`lucide-react`)

---

## ✨ 核心功能說明

1. **五天行程選單**：自由切換 5 天行程細節或「全部行程」彙整。
2. **主題標籤篩選**：依「陀螺/動漫」、「精品咖啡/奶茶」、「美式漢堡/河粉」、「經典景點」進行快速分類。
3. **老饕與動漫採購攻略小抄**：提供正宗港式奶茶點單秘訣（少甜/走甜）、現時點與朗豪坊採購指引。
4. **一鍵地址複製**：點擊卡片右上角地址圖示即可一鍵複製地址，方便貼入 Google Maps。
5. **港鐵與交通轉乘指引**：卡片特別標示港鐵路線、出口及步行時間。
